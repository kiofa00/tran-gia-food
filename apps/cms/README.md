# 🖼️ Universal Strapi Headless CMS (`apps/cms`)

Universal Content Management System for the Tran Gia Food monorepo platform.

## Features

- **Dynamic Translations & Text Copy**: Manage dynamic i18n labels (`vi`, `en`) for Customer, Shipper, Restaurant & Admin Web without app re-deployments.
- **Marketing Banners**: Manage promotional banners, carousels, and popup campaigns.
- **Help Center FAQs**: Dynamic support articles and FAQs.
- **Legal Policies**: Terms of Service and Privacy Policy management.

## Quick Start

```bash
# Run Strapi CMS in development mode (Port 1337)
pnpm --filter cms dev

# Access Admin Panel
http://localhost:1337/admin
```
